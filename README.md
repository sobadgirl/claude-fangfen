## 1. 三年三步

搞清楚你面对的是什么，比记一堆技巧有用。Anthropic 对国内用户的三次收紧，每一次都换了一个维度。

**第一阶段，认 IP。** 2024 到 2025 年上半年，只看请求从哪来。挂个代理就能绕，那时候大家用得挺舒服。

**第二阶段，认主体。** 2025 年 9 月开始封中国控股的公司实体，字节的 Trae 拿不到授权，国内中转服务商成批被封。个人开发者只要被判定为中国身份，随时可能掉。

**第三阶段，认人。** 2026 年 4 月起推行 KYC，第三方供应商 Persona 执行，要求手持政府签发的证件原件做实时拍照，外加人脸。不接受复印件、扫描件、数字证件、临时身份证。

到这一步，风向已经很清楚：它不再判断"你是不是机器人"，它在判断"你是不是一个能在美国被追责的自然人"。

据公开报道，这套系统用了 640 多项遥测信号，环境扫描频率到 5 秒一次，异常行为检测 40 多项。数字本身没法验证，但和社区的实际封号体验是对得上的。

## 2. 极高风险

这四件事，做了就是赌运气，不是做防护。

### 2.1 拼车、共享号

一个账号多人用，Anthropic 看到的是：早上中国 IP 登录，晚上美国 IP 登录；同一时刻好几台设备在线；浏览器指纹差异巨大；多个会话并发。

判定为账号倒卖，全员一起封，钱不退。闲鱼、群里那些"Max 拼车 ¥50 一个月"，能活两周算长寿。

### 2.2 代充、成品号

代充手里的卡，来源通常是黑卡或者套现卡。这类卡有个延迟引爆的特性：付款当场成功，Stripe 在几周到几个月后做 chargeback，钱被追回，账号按"支付欺诈"关联封禁。

客服的应对方式是换号，换来的号是同一批环境养出来的，接着封。再往后客服直接失联。

判断标准很简单：卖得比官方价低，又承诺封号包换，这个组合在数学上不成立。

### 2.3 虚拟卡、U 卡付款

2026 年最重要的一条变化：**识别方式从网络环境转向发卡行 BIN 段。**

卡号前 6 到 8 位决定成败。用 USDT 出入金、挂靠 VISA 或 Mastercard 的虚拟预付卡，在多轮清退里被整段拉黑。有用户反馈即使 IP 是干净的住宅段也照样被封，说明这一关根本不看你人在哪。

而且是付款成功后封。订阅生效几个小时，退款邮件就到了。

更麻烦的是连坐：同一张卡付过的其他账号会被一起扫到。

### 2.4 中转站、Sub2API、New API 分发

把账号额度通过反向代理转卖，或者用 OAuth 令牌接入第三方工具。Anthropic 2026 年 2 月修改文档，明确这类接入违反服务条款，之后开始批量清 Key。

中转站的账算得很明白：用户量大，额度在封号前就消耗完了，封了还能全额退款，直接资金损失有限。风险全在你这头，你付的钱拿不回来。

## 3. 高风险

单独一项不致命，凑在一起就构成"异常环境"这个结论。

### 3.1 IP 跳变

不用换国家，换城市就够。住宅 IP 但不是固定 IP 的，每次拨号换一个地址，一样会被抬走。

真正被记的不是"你用了哪个 IP"，是"你的 IP 变化频率像不像一个正常人的作息"。

### 3.2 指纹漂移

浏览器指纹、时区、语言、屏幕分辨率、字体列表、Canvas 渲染结果。这些东西组合起来是唯一标识。

换浏览器、换设备、换系统、装指纹插件、清 Cookie 后重登，都会让指纹变一次。变一次不要紧，变得比换衣服还勤就是信号。

时区跟 IP 对不上，是最常被抓的一条。IP 在洛杉矶，系统时区是东八区，这条不用算法也能看出来。

### 3.3 多设备并发

同一账号手机、笔记本、公司电脑、服务器同时在线。多设备本身官方允许，同时活跃才是问题。

Claude Code 默认强制同一时间只有一个会话，超过这个就不正常了。

### 3.4 注册完就高强度使用

新号没有任何历史行为，风控给不出"这是个正常人"的判断，只能靠观察。这时候你一天跑几百次调用，等于自己把结论写好了。

### 3.5 买来的 Gmail

二手邮箱的风控值是继承的。前一个用它的人做过什么，你无从知道，但记录跟着走。

## 4. 中风险

这些单看都是小事，问题是它们经常一起出现。

**账单地址和 IP 不在一个地方。** 卡是美国地址，IP 是新加坡，收货人姓名是拼音。三个国家的信息拼在一个账号上。

**年龄。** Anthropic 要求 18 岁以上，用 Yoti 做年龄判断。未成年人使用被识别出来，处理方式是封号加整月退款，社区里已经有过实际案例。

**频繁改资料。** 改密码、改邮箱、改支付方式、改姓名。每改一次都是一次重新审核。

**低质量邮箱。** 一次性邮箱、临时域名、明显批量注册的域名。

**机房 IP。** 这里要说句公道话：机房 IP 本身不是死罪，社区里有人用低共享的静态机房 IP 长期稳定。它的问题是纯净度不可控，同一段 IP 上别人干过什么你不知道，出事之后也没有换的余地。

住宅 IP 贵，买的是两件事：一是同一段地址上的邻居更干净，二是被封之后还有重开的可能。这跟"机房 IP 一定死"是两回事，别被人吓着，也别指望便宜的机房 IP 能扛住连坐。

## 5. 72 小时观察期

社区反复验证到的一个窗口：注册并付费之后的头 24 到 72 小时，是风控集中打分的时段。

这个阶段它在看七件事：

| 信号 | 权重 |
|---|---|
| 注册时的 IP 地理位置 | 高 |
| 付款卡的 BIN | 高 |
| 邮箱质量 | 高 |
| 24 小时内 token 用量 | 高 |
| 注册到付款的间隔 | 中，太快像机器人 |
| 24 小时内对话数 | 中 |
| system prompt 替换频率 | 中，像 API 滥用 |

表的权重是社区经验汇总，不是官方数据。但方向和实际封号案例能对上。

过了这三天不代表安全，代表你有了历史行为，风控有了判断依据。前三天没有。

## 6. 连坐

这是最容易被低估的一环。很多人以为封号是账号级别的事，换个号重开就行。实际不是。

会被一起标记的东西：

- **设备指纹**。同一台电脑、同一个浏览器配置，新号一眼被认出来。
- **支付方式**。同一张卡、同一个 Apple ID、同一个账单地址。
- **IP 段**。同一段地址上被封过，这段地址本身带上污点。
- **注册渠道特征**。同一批次的邮箱域名、同一个接码平台号段。

所以"被封了 10 张卡"这种情况会发生。不是运气差，是前一张卡留下的痕迹把后一张一起带走了。

真要重开，得把上面四项全部换掉，只换一项等于没换。这也是为什么自己折腾的人最后会去搞独立服务器：那不是为了性能，是为了让环境可以整个替换。

## 7. KYC 触发之后

触发条件大致是这几类：新号高频操作、IP 在多个国家或时区跳变、低质量邮箱、在不受支持的地区创建账号、用了 API 但没充值。

正常触发流程是 Persona 走一遍证件加人脸，五分钟能走完。

问题在结果。Anthropic 官方 FAQ 里专门有一条"为什么我的账号在验证之后被封了"，把封号原因列在这里：屡次违反使用政策、从不受支持的位置创建账户、违反服务条款、18 岁以下使用。

也就是说，验证通过不等于账号保住。它只是把判断所需的材料补齐了。

现实预期：国内身份证不在接受范围内，能提供的材料大概率凑不齐，社区里申诉恢复的案例极少。**把它当止损流程，别当救援流程。**

顺带一句提醒：Persona 的隐私条款里写明它有多个子处理器能接触用户数据，且允许数据用于改进反欺诈能力。上传证件之前自己权衡。

## 8. 已经封了怎么办

**第一件事，确认是哪种状态。** 别把"付款失败"当成"封号"，两者的处理完全不同。

| 页面表现 | 是什么 | 该做什么 |
|---|---|---|
| 提示某些请求可能违反使用政策 | Warning，还没封 | 立刻停同类请求，别换说法试探 |
| 要求身份验证、走 Persona | KYC | 见第 7 节 |
| 提示需要确认 18 岁以上 | 年龄验证 | 按邮件里的 Yoti 入口走 |
| 地区不可用 | 注册或登录受限 | 别重复注册 |
| 订阅失败、续费失败 | 支付问题 | 查账单，找支付渠道客服 |
| 账号已停用 | 封了 | 走官方申诉 |

**第二件事，算清楚钱在哪。** 通过 App Store 订阅的，退款走 Apple，不是走 Anthropic，路径和时效都不一样。直接刷卡的，看 Stripe 有没有发起退款。中转站和代充的钱，基本不可能追回。

**第三件事，申诉要不要写。** 官方邮件只说违反服务条款，不会告诉你具体哪一条。个人账号的申诉，成功率很低。如果你确实是误判，比如内容审核的假阳性，写清楚上下文、说明用途、附上具体请求记录，还有一点机会。批量模板化的申诉没有意义。

**第四件事，别急着开新号。** 环境没换就重开，新号大概率活不过一周，而且会把新环境也污染掉。

完整的止损和重开流程在 [use-claude-in-china](https://github.com/sobadgirl/use-claude-in-china)。如果不想自己一步步换，也可以看 [get-claude-in-china](https://github.com/sobadgirl/get-claude-in-china) 里我们做的事。

## 9. 自查表

对着打勾。勾得越多，离封号越近。

- [ ] 账号不是一个人在用
- [ ] 用过代充或者买过成品号
- [ ] 付款方式是虚拟卡 / U 卡
- [ ] 同时在用中转站
- [ ] 一个月内换过 IP 所在国家
- [ ] 系统时区和 IP 所在地对不上
- [ ] 手机、电脑、服务器同时在线
- [ ] 注册三天内跑过批量任务
- [ ] 邮箱是买的或者一次性的
- [ ] 账单地址、IP 所在地、姓名国籍三个对不上
- [ ] 最近频繁改过密码或支付方式
- [ ] 之前被封过，这次没换环境

一两条还能救，三条以上基本是在等邮件。

## 10. 常见问题

### Claude 账号被封了还能恢复吗

大概率不能。官方邮件只说违反服务条款，不告诉你具体哪一条。个人账号申诉成功率很低，只有内容审核假阳性这类误判还有一点机会。批量模板化的申诉没有意义，它看得出你在复制粘贴。

### Claude 封号前会给警告吗

偶尔给。页面提示某些请求可能违反使用政策，那就是警告阶段，账号还没封。这时候立刻停同类请求就还有救，别换个说法继续试边界——重复试探比偶发一次危险得多，API 账号尤其如此，违规是累计的。

### 用 VPN 登录 Claude 会被封吗

看用哪种。共享 VPN 出口（Surfshark、NordVPN 这类公共池）的 ASN 早被标成高风险，跟你在哪没关系，是这段地址上其他人做的事算到你头上。独享的静态线路风险小很多，但也不是免死金牌。

### Claude 拼车号能撑多久

一两周算长寿。判定逻辑很直白：多个 IP 短时间内登录、多设备指纹差异巨大、会话并发。三条凑齐就是账号倒卖，全员一起封，钱不退。

### Claude 代充为什么比官方便宜

因为卡不是他的。多数代充用的是黑卡或者套现卡，付款当场能过，Stripe 在几周到几个月后发起 chargeback，钱被追回，账号按支付欺诈关联封禁。你付的钱，他早就收走了。

### Claude 弹身份验证必须做吗

不做就用不了了。心理准备要有：验证通过不等于保住账号。官方 FAQ 里专门有一条「为什么我在验证之后被封了」，验证只是把判断材料补齐，结论照旧。

### 一个 Claude 账号能几台设备登录

官方允许你的手机、电脑、平板同时在线，但多设备同时活跃会触发风控。Claude Code 默认强制同一时间只有一个会话，超过这个就不正常了。两台电脑来回切换是最常见的死法。

### 换新电脑登录 Claude 会封号吗

新机器就是新指纹，跟旧机器交替在线等于「多套硬件指纹轮换」。真要用第二台，就远程连回主力机，别两边都装客户端。

### Claude 封号后订阅费能退吗

看支付渠道。走 App Store 的退款找 Apple，与 Anthropic 无关，时效也不一样。直接刷卡的看 Stripe 有没有发起退款。中转站和代充的钱基本追不回来。

### 大陆手机号能注册 Claude 吗

能收验证码，但号码本身在风控里有记录。接码平台的一次性号码等于直接在申请表上写「我在批量注册」。
